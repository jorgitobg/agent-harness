# Changelog

## 0.1.0

Changes since v0.0.1 (4 commits on main; see `git log v0.0.1..v0.1.0`).

### Added
- `CliConfirmation`: a fail-closed terminal prompt (only `y`/`yes` approves; empty input, noise, EOF or Ctrl-C refuse) and `CostEstimator` for models that report no cost (caller-supplied prices; an estimate, not an invoice).

### Fixed
- Cost accounting: unknown cost is now distinct from a reported zero, and `max_cost_usd` is enforced on known spend. No-op compaction no longer turns known spend into unknown; negative, non-finite or overflowing provider costs degrade to unknown instead of failing the call.
- Confirmation: calls whose name or escaped arguments do not fit the bounded preview are refused without a prompt, and control characters, newlines, C1 and bidi characters are shown as escapes.
- Evals: the denied-write task passes only when the model really requested the intended write, the guard returned an explicit `denied` for that call, the note is unchanged and the run ends with a final answer. Committed results were regenerated by the runner.

### Changed
- CI actions moved to current major versions.

### Known limits
- Traces recorded before this release stored a missing cost as `0.0`; they are read back as known-free spend and are not rewritten.
- Long tool arguments are refused rather than paged for review.
- Evals use scripted models; there is no evaluation over real models in this release.
